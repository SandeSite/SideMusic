# VIBE Music Website Template

A modern responsive music website built with:
- HTML
- CSS
- JavaScript
- Local SVG artwork (no external image links required)

## Open it
Double-click `index.html` to view the site.

## Main features
- Responsive navigation/menu
- Hero section
- Artist cards
- Release cards
- Genre filtering
- Demo music player with animated progress
- Newsletter form interaction
- Events button
- Mobile layout

The music player is a demo interface. It does not contain copyrighted audio files.
